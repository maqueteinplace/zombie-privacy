# Zombie Run — Política de Privacidade

Página pública PT-BR/EN: <https://maqueteinplace.github.io/zombie-privacy/>.

Esta é a cópia de publicação do diretório `privacy-site/` do repositório privado `maqueteinplace/zombie_play`. A fonte é mantida e validada no ramo `dev_zombie`; a branch pública `main` recebe o espelho somente junto a uma promoção de produção explicitamente solicitada. O GitHub Pages publica a raiz deste repositório somente após push em `main`.

Verifique o conteúdo com `node scripts/check-privacy.mjs`. Consulte [AGENTS.md](AGENTS.md) para o contrato de sincronização e publicação.
