Política de privacidade Privacy policy

Em resumo

Seu save fica local.

O Zombie Run não exige conta. O progresso é guardado no armazenamento privado do app ou do navegador; o app não envia saves para um servidor operado pelo desenvolvedor.

Compromisso do jogo

Sem perfil de jogador, sem anúncios integrados e sem ferramentas de analytics nesta versão.

  • ContaNão exigida
  • Ads / analyticsNão integrados
  • Save do jogoLocal
01 /

Quem somos

Zombie Run é um jogo de ação e exploração para Android e web. Nesta versão não há cadastro, backend do jogo ou envio do progresso para servidores do desenvolvedor.

02 /

O que fica salvo

O progresso — como checkpoint, áreas descobertas, nível, equipamentos e aparência — é salvo pelo Capacitor Preferences. No Android, usa o armazenamento privado SharedPreferences; na web, usa o armazenamento local do navegador (localStorage).

03 /

Permissões e conexão

O manifesto Android declara a permissão normal de Internet. No código do jogo revisado, o progresso não é transmitido ao desenvolvedor e não há integração de anúncios ou analytics. A permissão, por si só, não significa que dados do save sejam coletados.

04 /

Backup do Android

O app permite backup do sistema Android. Se o backup do dispositivo estiver ativado, o sistema ou o serviço de backup escolhido por você poderá incluir dados do app conforme as configurações da sua conta e do aparelho. O desenvolvedor não controla esse serviço.

05 /

Apagar seus dados

  • Android: Configurações → Apps → Zombie Run → Armazenamento → Limpar dados.
  • Web: apague os dados do site nas configurações do navegador usado para jogar.
  • Desinstalar o app remove os dados locais do dispositivo; cópias de backup do sistema podem seguir as próprias regras de retenção.
06 /

Hospedagem desta página

Esta política é servida pelo GitHub Pages. A infraestrutura do GitHub pode processar dados técnicos de acesso, como endereço IP, navegador, horário e página solicitada, conforme a política de privacidade do GitHub. Esta página não adiciona cookies de publicidade, analytics ou scripts de rastreamento.

07 /

Crianças e responsáveis

O jogo não solicita dados pessoais nem cria contas de jogadores. Responsáveis podem acompanhar o uso do app e entrar em contato se tiverem dúvidas sobre privacidade ou se acreditarem que uma informação pessoal foi enviada ao desenvolvedor.

08 /

Alterações

Se o funcionamento do jogo ou os serviços usados mudarem, esta política será revisada. A data no início identifica a versão vigente deste documento.

Dúvidas ou solicitações Fale com o desenvolvedor sobre esta política.

In brief

Your save stays local.

Zombie Run does not require an account. Progress is stored in the app's or browser's private storage; the game does not send saves to a server operated by the developer.

Game commitment

No player profiles, integrated ads, or analytics tools in this release.

  • AccountNot required
  • Ads / analyticsNot integrated
  • Game saveLocal
01 /

Who we are

Zombie Run is an action and exploration game for Android and the web. This release has no player registration, game backend, or transfer of game progress to developer-operated servers.

02 /

What is stored

Progress — such as checkpoints, discovered areas, level, equipment, and appearance — is saved with Capacitor Preferences. On Android it uses private SharedPreferences storage; on the web it uses the browser's local storage (localStorage).

03 /

Permissions and connectivity

The Android manifest declares the normal Internet permission. In the reviewed game code, progress is not transmitted to the developer, and there are no integrated ads or analytics. The permission alone does not mean save data is collected.

04 /

Android backup

The app allows Android system backup. If device backup is enabled, Android or the backup service you choose may include app data according to your account and device settings. The developer does not control that service.

05 /

Deleting your data

  • Android: Settings → Apps → Zombie Run → Storage → Clear data.
  • Web: clear this game's site data in the browser used to play.
  • Uninstalling removes local data from the device; system backup copies may follow their own retention rules.
06 /

This page's hosting

This policy is served by GitHub Pages. GitHub's infrastructure may process technical access data, such as IP address, browser, time, and requested page, under the GitHub Privacy Statement. This page does not add advertising cookies, analytics, or tracking scripts.

07 /

Children and parents

The game does not ask for personal data or create player accounts. Parents and guardians can supervise app use and contact the developer with privacy questions or if they believe personal information was sent to the developer.

08 /

Changes

If the game's behavior or services change, this policy will be reviewed. The date at the top identifies the current version of this document.
